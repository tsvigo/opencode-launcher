# opencode-launcher

Графический лаунчер проектов: показывает список папок из `/home/v/projects`,
по клику открывает Konsole в нужной папке и запускает в нём OpenCode.

## Назначение

Быстрый запуск рабочего окружения OpenCode в нужном проекте без ручного
ввода `cd` и команды запуска. Один клик по кнопке проекта.

## Возможности

- Кнопки проектов: имя папки, номер, автоматическая ширина под текст.
- Высота окна равна доступной высоте экрана.
- Сортировка: по алфавиту, по времени создания, по частоте запусков.
  Выбор и счётчики хранятся в `QSettings`.
- Поиск: многословный, каждое слово ищется отдельно в любой позиции.
  Терпимость к окончаниям: грубый стеммер русского языка
  (`кнопка` находит `кнопке`, `картинка` — `картинок`).
- Переключатель движка (сохраняется в `QSettings`):
  - `opencode v1` — `/home/v/.opencode/bin/opencode`;
  - `oc2 v2 (--standalone)` — `/home/v/.local/bin/oc2 --standalone`;
  - `oc2 v2` — `/home/v/.local/bin/oc2` (по умолчанию).
- Один экземпляр: второй запуск не открывает новое окно,
  а поднимает уже работающее.

## Команда запуска проекта

Режим по умолчанию (`oc2 v2`):

```bash
konsole --workdir '<ПУТЬ>' -e bash -c "cd '<ПУТЬ>' && /home/v/.local/bin/oc2-check && /home/v/.local/bin/oc2; exec bash"
```

С флагом `--standalone` добавляется `--standalone` после `oc2`.
Хвост `exec bash` не даёт терминалу закрыться после выхода из OpenCode.

## Внешний вид

- Поле поиска: тёмно-зелёный фон `#14402C`, светлый текст `#E8F5EC`,
  подсказка `#9DBFA9`.

## Сборка

Требуется Qt 6 или Qt 5 с модулями Widgets и Network, CMake 3.16+.

```bash
mkdir build && cd build && cmake .. && make
```

Бинарник: `build/opencode-launcher`.

## Запуск

```bash
./build/opencode-launcher
```

Ярлык: `~/.local/share/applications/opencode-launcher.desktop`.

## Зависимости окружения

- Терминал: `konsole` (запасной вариант — `xterm`, `gnome-terminal`).
- OpenCode: `opencode` v1 либо `oc2` + `oc2-check` для v2.
- Пути к бинарникам и папке проектов заданы константами в `main.cpp`.

## Ограничения

- `kProjectsRoot`, `kOpencodeBinary`, `kOc2Binary`, `kOc2CheckBinary`
  захардкожены под текущую машину.
- Стеммер грубый: чередования в корне (`кот/котики`) не покрываются.
- Поднятие окна зависит от политики графической среды:
  на X11/KDE работает, на Wayland окно может только мигнуть.
- Настройки лежат в `QSettings` (`opencode-launcher/opencode-launcher`).
